# RAG、Chatbot、Agent 的能力边界

| 范式 | 能力 | 典型失败模式 |
| --- | --- | --- |
| RAG | 检索增强回答，弱执行 | 能回答“怎么做”，但无法稳定“做出来”；检索噪声会放大幻觉 |
| Chatbot | 对话生成，弱工具编排 | 多轮看似流畅，但跨步骤任务易丢上下文与状态，难以端到端交付 |
| Agent | 可规划、可调用工具、可验证、可复现 | 若缺少约束与监控，可能出现错误工具调用、循环执行或成本失控 |

**结论：你的系统是“任务执行型Agent”，而非“问答型Bot”。**
